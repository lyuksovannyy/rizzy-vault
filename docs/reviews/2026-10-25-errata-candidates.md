# Errata candidates in Accepted ADRs, 2026-10-25

This list collects text in **Accepted** (or Partially superseded) ADRs that no longer matches the code, the shipped files or a later Accepted ADR. It was compiled from the [2026-10-25 gap review](2026-10-25-adr-gap-review.md) (raw ids in brackets) and from a scripted scan of every Accepted ADR for migration file names and for ADRs still called "Proposed".

None of these ADRs was edited. Changing the Decision or Consequences of an Accepted ADR takes a new Proposed ADR that names each superseded part and gives its full replacement text ([ADR 0020](../adr/0020-partial-supersession.md) point 9). The owner may also judge some rows to be typo or link fixes, which [the ADR index](../adr/README.md) (line 30) allows on an Accepted ADR. The "Suggested correction" column is a starting point for that erratum. It is not a decision.

Where the living docs (CRYPTO.md, THREAT_MODEL.md, HANDOFF.md) state the same fact, they were corrected on branch `wip/docs-hygiene` and cite the ADR. These rows record what is still stale in the ADR text itself.

## 1. Numbers allocated in parallel that shipped under other values
