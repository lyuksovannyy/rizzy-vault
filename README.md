# rizzy-vault

Self-hostable, end-to-end encrypted password manager written in Rust — Bitwarden-style zero-knowledge core, 1Password-inspired UX and item sharing, AliasVault-style aliases with a built-in receive-only mailbox.

**Status:** planning. No code yet. See [`docs/ROADMAP.md`](docs/ROADMAP.md) for milestones and MoSCoW scope, and [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for server architecture and Docker/Podman deployment.
