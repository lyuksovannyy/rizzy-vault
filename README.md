# rizzy-vault

Self-hostable, end-to-end encrypted password manager written in Rust — Bitwarden-style zero-knowledge core, 1Password-inspired UX and item sharing, AliasVault-style aliases with a built-in receive-only mailbox.

**Status:** pre-alpha (M0, Foundations). No product code yet. **Not for real secrets.** See [`docs/ROADMAP.md`](docs/ROADMAP.md) for milestones and MoSCoW scope, and [ADR 0010](docs/adr/0010-server-shape.md) for the server's shape and its Docker/Podman deployment profiles.
